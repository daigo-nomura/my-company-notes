# アイデア精査レポート — 2026-04-28

## 総評

今回収集した中で最も有望なのは「特定のニッチ職種が今まさに困っている業務ツール」の領域。ハンドメイド作家・個人塾・中小運送会社のいずれも「専用アプリがない or 高すぎる」という明確な空白が存在し、オーナーが3ヶ月以内にMVPを作れる技術的難易度に収まっている。EigoCheckとの相乗効果は低いものが多いが、作れる条件・マネタイズ可能性のバランスを考えると「次の収益の柱」として並行開発できる候補が揃っている。

## 🥇 第1位: ハンドメイド作家向け原価計算・在庫管理iOSアプリ

**総合スコア: 75/100**

| 評価軸 | スコア | コメント |
|--------|--------|----------|
| 実装難易度 | 18/20 | SwiftUI + CoreData だけで完結。材料マスタ・商品マスタ・売上履歴の3テーブル構成。計算ロジックはシンプルな四則演算。1〜1.5ヶ月でMVP可能 |
| 市場規模 | 14/20 | minne登録者1,400万人超、出品作家数十万人。課金率は低いが絶対数は十分。日本語市場特化で海外競合も薄い |
| 競合の少なさ | 17/20 | App Storeで「原価計算 ハンドメイド」の日本語・使えるアプリはほぼ存在しない。直接競合2件以下 |
| EigoCheckとの相乗効果 | 11/20 | SwiftUIコンポーネント・OpenAI API連携ロジックは流用可。ユーザー層は重ならないが技術スタック完全一致 |
| マネタイズ可能性 | 15/20 | 買い切り480〜980円。minne出品者コミュニティ（X/Instagram）で口コミが広がりやすい。6ヶ月以内に月3万円達成は現実的 |

**なぜ今のオーナーに向いているか:**
EigoCheckで培ったSwiftUI + CoreData + App Store申請の経験がそのまま活きる。英語キーボードアプリよりもUIがシンプルで、複雑なネットワーク処理・Extension APIが不要。ゼロから始めるよりも2倍速で開発できる。「原価すら把握できていない作家が赤字のまま続けている」という課題はリアルで、ユーザーが「使ってよかった」を実感しやすい。

**MVP設計案:**
- **最小機能:**
  1. 材料費登録（材料名・単価・購入単位）
  2. 商品登録（材料を組み合わせて使用量を入力→原価自動計算）
  3. 販売価格提案（原価 × 希望利益率 → 推奨価格表示）
  4. 売上記録（販売した日・価格・数量）
  5. 月次サマリー（売上・原価・利益を棒グラフで表示）

- **技術スタック:** SwiftUI + CoreData（ローカル保存）+ Charts framework（iOS 16+）
- **想定工数:** 設計1週間 → 実装4〜5週間 → テスト・審査2週間 = 計2ヶ月以内
- **最初の収益化方法:** 買い切り480円でリリース → 無料版（商品登録5件まで）+ 有料版（無制限）のフリーミアムに移行

**リスク・注意点:**
- ユーザーが「Excelで十分」と思っている層が多い → アプリの価値を伝えるマーケティング（Reels・TikTok動画）が必要
- minne/Creema API は公開されていないため、プラットフォームとの連携は手動入力で妥協する
- 「有料でアプリを買う」習慣がないハンドメイド作家層には無料スタートが重要

## 🥈 第2位: 個人塾・家庭教師向け生徒管理＋月謝請求iOSアプリ

**総合スコア: 74/100**

| 評価軸 | スコア | コメント |
|--------|--------|----------|
| 実装難易度 | 17/20 | SwiftUI + CoreData + PDFKit。生徒マスタ・出席記録・請求書生成の3機能。PDFKit で請求書テンプレートを実装するのが唯一の新要素 |
| 市場規模 | 13/20 | 個人塾・家庭教師は全国数万〜十数万人。少人数だが「毎月使う」定期利用なのでサブスクに向いている |
| 競合の少なさ | 16/20 | PC向けSaaSは複数存在するが月額1万円以上が多い。モバイル日本語特化で月980〜1,980円という価格帯のアプリはほぼない |
| EigoCheckとの相乗効果 | 14/20 | 英語塾・語学教室の先生がEigoCheckユーザーと重なる可能性が高い。EigoCheckユーザーへのクロスセル通知で初期ユーザーを獲得できる |
| マネタイズ可能性 | 14/20 | 月額980〜1,980円のサブスク。50人で月5〜10万円。塾向けツールは解約率が低く長期収益が見込める |

**なぜ今のオーナーに向いているか:**
EigoCheckのキーボードを使うユーザーの中には英語塾や語学教室の先生が一定数いる。「EigoCheckのユーザーが次に欲しいもの」として自然な導線が引ける。PDFKitは初めての実装になるが、日本語ドキュメントと事例が豊富で独学可能。

**MVP設計案:**
- **最小機能:**
  1. 生徒登録（名前・学年・連絡先・月謝金額）
  2. 出席記録（日付・科目・メモ）
  3. 月謝請求書PDF生成・共有（PDFKit）
  4. 月次収入サマリー

- **技術スタック:** SwiftUI + CoreData + PDFKit + iCloud同期（任意）
- **想定工数:** 設計1週間 → 実装5週間 → テスト・審査2週間 = 計2ヶ月弱
- **最初の収益化方法:** 月額980円サブスク（生徒10人まで無料 → 11人以上は有料）

**リスク・注意点:**
- 市場規模が小さいため月10万円到達には時間がかかる（1年以上かかる可能性）
- 既存の大手塾管理ソフトとの比較で「機能が少ない」と言われる可能性 → 「シンプルなことが強み」と徹底する
- EigoCheckからの導線がうまく機能しないと初期ユーザー獲得が難しい

## 🥉 第3位: 中小運送会社向け傭車管理iOSアプリ

**総合スコア: 73/100**

| 評価軸 | スコア | コメント |
|--------|--------|----------|
| 実装難易度 | 14/20 | SwiftUI + Firebase/Supabase。BtoB業務ロジック（傭車先マスタ・案件登録・月次精算）は初〜中級者にはデータモデル設計が壁。3ヶ月以内のMVPはタイト |
| 市場規模 | 16/20 | 国内運送会社約6.3万社。10〜50台規模の中小は数万社。1社月5,000円でも50社で月25万円 |
| 競合の少なさ | 19/20 | 「傭車管理専用iOSアプリ」はApp Storeでほぼ存在しない。完全な空白地帯 |
| EigoCheckとの相乗効果 | 7/20 | ユーザー層・スキル・コードの重なりが小さい。業界インサイダー知識が代わりの強みになる |
| マネタイズ可能性 | 17/20 | 月額5,000〜10,000円 × 10社 = 月5〜10万円。業界人脈があれば6ヶ月以内に現実的 |

**なぜ今のオーナーに向いているか:**
デジタコ×運行管理システムのメーカー勤務という圧倒的な業界インサイダー優位がある。中小運送会社が「何に困っているか」「既存システムのどこが使いにくいか」を誰より知っている。競合ゼロの市場で専門知識を持つのは他の開発者にはない強み。

**MVP設計案:**
- **最小機能:**
  1. 傭車先登録（会社名・連絡先・単価設定）
  2. 配送案件登録（日付・区間・傭車先・運賃）
  3. 月次精算レポート（傭車先別の請求金額集計）
  4. PDF出力（月次支払確認書）

- **技術スタック:** SwiftUI + Supabase（クラウドDB・複数デバイス共有に対応）+ PDFKit
- **想定工数:** 設計2週間 → 実装6〜7週間 → テスト・審査2週間 = 計3ヶ月ギリギリ
- **最初の収益化方法:** 30日無料トライアル → 月額4,980円（社単位）。最初の5社は業界人脈から直接営業

**リスク・注意点:**
- 中小運送会社は「自分でアプリを検索して導入する」文化が薄い。SEO・App Store流入だけでは難しく、直接営業が不可欠
- 3ヶ月で作れる条件のギリギリライン。Supabaseの学習コストが予想外に高くなる可能性
- 会社のiPhoneにインストールしてもらうための IT管理・信頼性の壁（MDM・プライバシーポリシー）
- 「営業できる5社の人脈があるか」が成否を分けるため、ここが最大リスク
