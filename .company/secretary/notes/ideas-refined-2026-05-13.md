# アイデア精査レポート — 2026-05-13

## 総評

今回の収集では「法規制の後押し」「iOS 26タイミング」「業界インサイダー優位」という3つの好条件が重なるアイデアが揃った。特に運送業×日報デジタル化は2025年4月の義務化直後であり、市場のニーズが法的に確定している点で他を圧倒する。EigoCheck起点で考えると「英語ライティングノート」は既存コードと技術スタックの流用率が高く、最短リリースが可能なオプションとして第2位に浮上した。

## 🥇 第1位: 運転日報 音声入力→PDF自動生成 iOSアプリ

**総合スコア: 76/100**

| 評価軸 | スコア | コメント |
|--------|--------|----------|
| 実装難易度 | 17/20 | Speech Framework（標準）+ PDFKit（標準）+ SwiftUI。外部APIほぼ不要。EigoCheckとは別技術領域だが、どちらも「標準フレームワーク完結」で組み合わせやすい。3ヶ月MVPは現実的 |
| 市場規模 | 15/20 | 日本の運送事業者約6万社。配車管理システム導入率14.9%＝85%超が非デジタル。2025年4月義務化で今すぐニーズ。ただしBtoBの営業力が一定必要 |
| 競合の少なさ | 18/20 | 「音声入力→日報PDF」に特化したiOSアプリはほぼゼロ。総合運行管理の一機能として埋もれているだけで、単機能アプリとしての空白は明確 |
| EigoCheckとの相乗効果 | 8/20 | ユーザー層は全く異なる。ただしSpeech Framework・PDF生成・SwiftUIのコードパターンは技術スタックとして蓄積できる。スキルのポートフォリオ拡大には貢献 |
| マネタイズ可能性 | 18/20 | 月額980〜1,980円でBtoB継続課金。100社獲得で月10〜20万円。法的義務化によりROI説明が簡単で営業しやすい。チャーンが低い（業務フロー依存） |

**なぜ今のオーナーに向いているか:**
- **業界インサイダー優位が決定的**：デジタコ・運行管理システム・トラック制御部品メーカー勤務という経歴は、競合がSaaS系スタートアップでは絶対に持てないリアルな現場知識。「日報に何を書くか」「どの項目が法的に必要か」を知っているだけで、競合との差が埋められない
- 2025年4月の義務化直後で、「今すぐ必要」という顧客心理が最高潮
- 勤務先のネットワーク（中小運送会社との接点）を活かした初期ユーザー獲得が可能

**MVP設計案:**
- **最小機能**:
  1. ドライバーが音声で「出発地・到着地・距離・積荷・出発時刻・到着時刻」を読み上げ
  2. Speech FrameworkがテキストにConvert
  3. 法定様式に合わせたPDFを自動生成
  4. AirDropまたはメール送信で管理者へ
- **技術スタック**: SwiftUI + Speech Framework + PDFKit（全て標準。外部APIコスト0）
- **想定工数**: 設計2週間・実装6週間・テスト2週間・ストア審査2週間 = 約3ヶ月
- **最初の収益化方法**: 月額980円（7日間無料トライアル）。初期30社をオーナーの業界人脈でハンドオフ営業

**リスク・注意点:**
- BtoBの無料→有料転換には対面または電話営業が必要になる場合がある（ソロ開発者の弱点）
- 法定様式が都道府県・事業者区分で異なる可能性→MVP段階は一般貨物自動車運送事業の標準様式のみに絞る
- 点呼記録・アルコールチェックとの連携を求められるが、最初のMVPには含めない判断が重要

| 評価軸 | スコア | コメント |

| 競合の少なさ | 13/20 | Grammarlyはある。ただし「日本語UI + ビジネス英語 + メモアプリ一体型」は空白。差別化ポイントが明確 |
| EigoCheckとの相乗効果 | 19/20 | EigoCheckの技術（APIコール設計・差分表示UI・課金実装）をほぼ全流用。EigoCheckユーザーへのアップセルルートが自然に発生 |
| マネタイズ可能性 | 11/20 | 月額300〜500円のフリーミアム、またはEigoCheck Proバンドル。ただし月3〜10万円の達成には数百〜数千ユーザー必要。BtoCは数が必要 |

**なぜ今のオーナーに向いているか:**
- EigoCheckで培った実装ノウハウ・APIプロンプト設計・UI設計をほぼ再利用できるため、実質1ヶ月以内でMVPが完成する可能性がある
- EigoCheckのユーザーベースに対してアップセルできる唯一のアイデア
- 「ビジネス英語 + 日本語UI」の差別化はマーケティングメッセージとして明確

**MVP設計案:**
- **最小機能**:
  1. ノートアプリ（シンプルなテキストエディタ）
  2. 段落を選択してワンタップで英文添削
  3. 修正箇所のハイライト + 日本語で理由説明
  4. Share Extensionでメール/Slack/X下書きからも呼べる
- **技術スタック**: SwiftUI + Claude API（EigoCheckと共通）+ Core Data
- **想定工数**: 設計1週間・実装4週間・テスト1週間・審査2週間 = 約2ヶ月
- **最初の収益化方法**: EigoCheckユーザーへの無料提供（口コミ獲得）→新規は月額500円

**リスク・注意点:**
- Grammarlyとの差別化を説明するコピーライティングが重要（技術ではなくポジショニング勝負）
- API費用がユーザー増加に比例するため、フリーミアムは使用回数上限を設ける必要あり
- 英語学習市場は既存アプリのブランド力が強く、ASO（App Store最適化）が難しい

  3. 各ステップの期限日を入力→カレンダー通知
  4. 「あと○日で期限」のリマインダー
- **技術スタック**: SwiftUI + EventKit + UserNotifications + JSONベースのルールDB
- **想定工数**: 設計1週間・実装4週間・データ収集2週間・テスト1週間・審査2週間 = 約2.5ヶ月

**リスク・注意点:**
