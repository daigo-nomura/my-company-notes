## 🥇 第1位: 傭車管理＋配送完了報告アプリ（運送業向け）
**総合スコア: 83/100**

| 評価軸 | スコア | コメント |
|--------|--------|----------|
| 実装難易度 | 17/20 | SwiftUI + Supabase (REST API) のみで実装可能。GPS+カメラ機能はiOS標準で対応。デジタコ連携は不要 |
| 市場規模 | 16/20 | 中小運送会社（10〜50台）は国内で数万社。1社あたり月額3,000〜10,000円でも十分な市場 |
| 競合の少なさ | 18/20 | 傭車管理単体アプリはApp Storeにほぼ存在しない。大手システムの高価格帯とガラガラの中間市場 |
| EigoCheckとの相乗効果 | 10/20 | ユーザー層は完全に別。ただしSwiftUI/iOS開発スキルは完全流用可。コードの再利用はほぼなし |
| マネタイズ可能性 | 20/20 | 月額3,000〜5,000円×20社で月6〜10万円が6ヶ月以内に現実的。業界人脈で直接営業可 |

**なぜ今のオーナーに向いているか:**
- 業界インサイダーとしての営業ルートが存在する（勤務先の顧客・取引先）
- 「傭車管理」の痛点を自分が体感して知っている → ユーザーインタビュー不要でMVP設計できる
- 競合が少なく、最初の10〜20社を直接営業で獲得できれば黒字化が見える
- 2024年問題の政策的追い風で「今すぐデジタル化したい」需要が顕在化

**MVP設計案:**
- **最小機能**: ①傭車案件登録（荷主・日付・ドライバー・金額・傭車先）②月末精算一覧PDF出力 ③配送完了報告（写真1枚+コメント+GPS）→荷主へメール/LINEで自動送信
- **技術スタック**: SwiftUI + Supabase (PostgreSQL + REST API) + SendGrid API（メール送信）
- **想定工数**: 3ヶ月（MVP: 月1〜2、テスト: 月2〜3、リリース: 月3終盤）
- **最初の収益化方法**: 初期無料→30日後に月額3,000円。まず勤務先関係者の運送会社3〜5社に無料モニター依頼

**リスク・注意点:**
- BtoB営業は一社一社のクローズが必要で、SNSマーケだけでは獲得できない
- 中小運送会社のITリテラシーが低い → UIを極端にシンプルにしないとチャーンが高まる
- 既存の大手システム担当者が「新しいツールを入れたくない」という現場抵抗
- 勤務先との利益相反（会社が同種ツールを作る可能性）→ 社内規定の確認が必要

## 🥈 第2位: ビジネス英語フレーズ辞書アプリ（EigoCheck横展開）
**総合スコア: 78/100**

| 評価軸 | スコア | コメント |
|--------|--------|----------|
| 実装難易度 | 19/20 | JSON辞書データ + SwiftUI + ウィジェット。AI APIは不要（フレーズはキュレーション済みデータ）。最もシンプル |
| 市場規模 | 14/20 | ビジネスパーソンの英語学習需要は大きいが、競合も多い。差別化が問われる |
| 競合の少なさ | 14/20 | 一般英語フレーズ集は多いが「ビジネスシーン特化×コピペ即使用」のキーボード連携は少ない |
| EigoCheckとの相乗効果 | 19/20 | EigoCheckユーザーへのクロスプロモーション直結。Keyboard Extension の基盤コードを流用可能 |
| マネタイズ可能性 | 12/20 | 買い切り¥480〜980が現実的。月3〜10万円は難しいが、EigoCheckとのバンドル戦略で補完可能 |

**なぜ今のオーナーに向いているか:**
- EigoCheckの既存コード（Keyboard Extension）がほぼそのまま流用できる
- 初リリースから次のアプリへのつなぎとして、学習コストが低い
- EigoCheckのApp Storeページからクロスプロモーションで自然流入が見込める
- フレーズデータはキュレーション済みのCSV/JSONで十分。AI APIコストがかからない

**MVP設計案:**
- **最小機能**: ①シチュエーション別フレーズ集（メール・会議・交渉・断り方 各30〜50フレーズ）②1タップコピー ③ホーム画面ウィジェット（今日のビジネスフレーズ）
- **技術スタック**: SwiftUI + ローカルJSON + WidgetKit（iOS ウィジェット）
- **想定工数**: 1〜1.5ヶ月（コンテンツ制作に時間がかかるが実装は軽い）
- **最初の収益化方法**: 買い切り¥480 + ¥480でプレミアムフレーズ追加（In-App Purchase）

**リスク・注意点:**
- フレーズの「品質・量」が全て。コンテンツ制作に予想以上の時間がかかる
- 単体で月3〜10万円に届かない可能性が高い → EigoCheckとのセット販売戦略が必要
- 大手アプリ（Eijiro・Weblio系）の無料フレーズページと直接比較される

## 🥉 第3位: 個人塾・家庭教師向け月謝管理＋請求書アプリ
**総合スコア: 76/100**

| 評価軸 | スコア | コメント |
|--------|--------|----------|
| 実装難易度 | 17/20 | SwiftUI + SwiftData + PDF生成（PDFKit）のみ。Supabaseが必要なら追加だが、オフライン完結でも成立 |
| 市場規模 | 13/20 | 個人塾・家庭教師は全国数十万人規模だが、アプリを使う層はその一部 |
| 競合の少なさ | 18/20 | freee・マネーフォワードは高機能すぎ。塾特化の月謝管理アプリはApp Storeで数件のみ |
| EigoCheckとの相乗効果 | 8/20 | 教育×英語という接点はあるが、ユーザー重複は少ない。コード流用はゼロに近い |
| マネタイズ可能性 | 20/20 | 月額500〜1,500円×50塾で月2.5〜7.5万円。freeeより安い価格帯で十分に成立可能 |

**なぜ今のオーナーに向いているか:**
- SwiftData + PDF生成だけで完結するため、バックエンド設計が不要
- 「freeeより安い・シンプル」という明確な差別化ポジションが取れる
- 個人塾は口コミで広がりやすく、一人が使い始めると周囲に紹介する文化がある
- 請求書の雛形+月謝自動計算という明確な価値を1機能で示せる

**MVP設計案:**
- **最小機能**: ①生徒登録（氏名・学年・月謝額）②月謝一覧（今月の支払い状況チェック）③請求書PDF出力（テンプレート1種）
- **技術スタック**: SwiftUI + SwiftData + PDFKit（全てApple標準フレームワーク）
- **想定工数**: 2〜2.5ヶ月（設計1週間 + 実装6週間 + テスト2週間）
- **最初の収益化方法**: 無料（生徒5名まで）→ 月額¥600 or 買い切り¥1,200（無制限）

**リスク・注意点:**
- 個人情報（生徒の情報）を扱うため、プライバシーポリシーの整備が必須
- 既存のfreee・マネーフォワードの無料プランで事足りると思う層もいる
- 教育系アプリはApp Storeのレビュー管理が厳しく、低評価がつくと挽回が難しい
