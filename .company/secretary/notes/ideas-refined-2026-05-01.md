# アイデア精査レポート — 2026-05-01

## 総評

今回のタスク1・2で収集したアイデアは、英語学習市場の深化という大きな潮流に乗るものが多く、EigoCheckユーザーへの横展開という軸で一貫した価値を持つ。2026年時点でAI添削・AI発音フィードバックは市場が証明済みの需要であり、スピークバディ500万DLという数字がその規模を裏付けている。ただしスピーキング系は競合が強く、**「ライティング×AI添削」という軸でEigoCheckとのシナジーを最大化するアプローチが最も現実的**な選択肢である。

## 🥇 第1位: AI英語日記添削アプリ「DailyEnglish」

**総合スコア: 88/100**

| 評価軸 | スコア | コメント |
|--------|--------|----------|
| 実装難易度 | 18/20 | SwiftUI + Claude API のみで成立。EigoCheckの添削エンジン（API呼び出し部分）がほぼそのまま流用可能。UIは「日記入力→添削表示→保存」のシンプル3画面 |
| 市場規模 | 16/20 | スピークバディ500万DLで英語学習市場の規模は実証済み。「日記を書いて添削」という需要はJournaly（英語ネイティブ向け）が存在証明。日本人向けに特化すれば数万人規模のターゲットに届く |
| 競合の少なさ | 17/20 | App Storeで「英語 日記 添削」検索すると直接競合は2件以下。Grammarlyは高額（月額30ドル）・英語圏UI。スピークバディ・Speakはスピーキング特化でライティング日記には弱い |
| EigoCheckとの相乗効果 | 20/20 | 完全同一ユーザー層（英語を書きたい日本人）。EigoCheckはキーボード→短文添削、DailyEnglishはアプリ→長文日記添削として姉妹アプリ化できる。相互バナー誘導で顧客獲得コストゼロ |
| マネタイズ可能性 | 17/20 | フリーミアム（3日分は無料、以降は月額480〜980円）。EigoCheckユーザー基盤からの誘導で初期100人獲得が現実的 → 月5〜10万円を3〜4ヶ月で達成可能。API費用はClaudeのキャッシュ機能活用で月1〜2万円以内に抑制可能 |

**なぜ今のオーナーに向いているか:**
EigoCheckで培った「AI添削 × iOS」のスタックがそのまま使える。新たに習得するAPIもライブラリもなく、知らない設計領域がゼロ。SwiftUIのUIもシンプルな3画面構成で実装難易度が低い。EigoCheckユーザーへのクロスプロモーションで初期ユーザー獲得の最大の壁（0→1）を乗り越えられる。「小さく確実に稼ぐ」志向にも完全合致。

**MVP設計案:**
- **最小機能**: ①英語日記テキスト入力画面、②AI添削フィードバック表示（文法・表現の修正提案）、③過去の日記一覧（Core Data保存）
- **技術スタック**: SwiftUI + Claude API（Haiku or Sonnet）+ Core Data（ローカル保存）。サーバーレスで完結 → インフラコストゼロ
- **想定工数**: 4〜6週間（EigoCheckコード流用でUI実装1週、API連携1週、テスト・審査対応2週）
- **最初の収益化方法**: 無料で3回添削 → 月額480円のサブスクリプション。EigoCheckのApp Store説明ページに「姉妹アプリ」バナーを追加して誘導

**リスク・注意点:**
- Claude APIのレスポンス速度・コストが収益性に影響。Prompt Cachingとバッチ送信で最適化必要
- 「日記を毎日書く」ハビットのチャーン（解約）リスク。通知・ストリーク機能を初期から入れる
- Duolingo等が日記モードを追加したら競合になる可能性。ただし大手の動きは遅い

## 🥈 第2位: 英語ライティングスタイル変換アプリ「ToneTune」

**総合スコア: 77/100**

| 評価軸 | スコア | コメント |
|--------|--------|----------|
| 実装難易度 | 17/20 | SwiftUI + Claude API + iOS Share Extension。EigoCheckと同じアーキテクチャ。Share ExtensionでSafari・メール・LINEから直接テキストを渡せる |
| 市場規模 | 14/20 | 「英語でビジネスメールを書く」日本人は限定的。ただしリモートワーク・グローバル化で需要拡大中。日記添削より狭いが、課金意欲（ビジネスユース）は高め |
| 競合の少なさ | 14/20 | GrammarlyのTone Detector機能が競合だが、日本語UIでビジネスメール変換に特化したものは少ない。ただしGemini・ChatGPTアプリも代替として使われている |
| EigoCheckとの相乗効果 | 17/20 | 「キーボードで短文を添削（EigoCheck）→アプリでメール全文のトーンを変換（ToneTune）」という使い分けで相互補完的。ユーザー誘導がスムーズ |
| マネタイズ可能性 | 15/20 | 月額480円 or 買い切り1,200円。ビジネスユーザーは課金意欲が高いが、ChatGPTアプリで無料代替されるリスクあり。月3〜5万円達成は3〜4ヶ月で可能 |

**なぜ今のオーナーに向いているか:**
EigoCheckと同じ技術スタックで、追加学習ゼロで実装できる。Share Extension（他アプリからの呼び出し）はEigoCheckのキーボード拡張と同系統のiOS拡張機能で、既にその仕組みを理解済み。「ビジネス文体↔カジュアル文体」「SNS投稿向けに短縮」など明確なユースケースが複数あり、バリエーション展開しやすい。

**MVP設計案:**
- **最小機能**: ①テキスト入力 or Share Extensionで受け取り、②変換モード選択（ビジネス丁寧／カジュアル／SNS短縮）、③変換結果をコピー
- **技術スタック**: SwiftUI + Claude API + Share Extension
- **想定工数**: 3〜5週間（DailyEnglishより機能がシンプル。Share Extension実装に1週追加）
- **最初の収益化方法**: 無料5回変換 → 月額480円 or 買い切り980円

**リスク・注意点:**
- ChatGPT・Geminiアプリが「無料で同じことができる」という認識がある。差別化として「日本人ビジネスマン向けに最適化されたプロンプト」「ワンタップで変換完了のUX」を前面に出す必要あり
- 「英語を書く機会がある日本人」というニッチ市場。マーケティングチャンネルが限定的

## 🥉 第3位: 英語シャドーイング発音採点アプリ「EchoScore」

**総合スコア: 70/100**

| 評価軸 | スコア | コメント |
|--------|--------|----------|
| 実装難易度 | 14/20 | AVFoundation + OpenAI Whisper API で音声認識は実装可能だが、「発音採点」のロジック精度が難しい。スピークバディのコピーキャット機能（抑揚のカラオケ採点）は独自アルゴリズムで、再現に時間がかかる |
| 市場規模 | 18/20 | 英語学習市場全体にリーチ可能。スピークバディ500万DLで規模証明済み。発音に悩む日本人英語学習者は非常に多い |
| 競合の少なさ | 10/20 | スピークバディが強力な競合。Speakも有力。直接競合が3件を超えており、差別化のポイントが見えにくい |
| EigoCheckとの相乗効果 | 13/20 | 英語学習ユーザー層は重なるが、スピーキング（音声）とライティング（テキスト）は別スキルで、ユーザー体験の連続性は低め |
| マネタイズ可能性 | 15/20 | 月額480〜980円で設定できるが、スピークバディとの直接比較になりやすく、月額1,500〜2,000円の大手に対して「なぜこちらを使うか」の回答が必要 |

**なぜ今のオーナーに向いているか:**
市場規模という点では最も有望だが、実装難易度とスピークバディの壁が高い。ただし「シャドーイング特化 × 日本語UI × 低価格（月額480円）」で差別化できれば中位市場を取れる可能性はある。SwiftUI + Whisper APIの組み合わせはWeb上にサンプルコードが多く、初〜中級Swiftでも実装できるレベル。

**MVP設計案:**
- **最小機能**: ①お手本音声の再生、②ユーザーの録音、③Whisper APIでテキスト変換→お手本テキストと比較してスコア表示
- **技術スタック**: SwiftUI + AVFoundation + OpenAI Whisper API
- **想定工数**: 6〜10週間（音声処理・採点UIが複雑で工数増。発音採点の精度チューニングに時間がかかる可能性）
- **最初の収益化方法**: 無料5回→月額480円。コンテンツ（お手本音声）を定期的に追加してサブスク継続率を維持

**リスク・注意点:**
- スピークバディが既に「コピーキャット」という類似機能を投入済み。後発として勝つには明確な差別化が必要
- 発音採点の精度が低いとレビュー評価に直結。MVP品質でのリリースがリスクになる
- 想定工数が長く、3ヶ月以内MVP完成が不確実。第3位とした主な理由
