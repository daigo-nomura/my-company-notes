## 総評

今回は「運送業界特化SaaS」「ニッチ職種向けBtoB」「EigoCheck横展開」の3軸で有望候補が出揃った。特にオーナーが業界インサイダーとして実態を把握している**運送業向けの傭車管理×点呼記録アプリ**は、競合の空白・法的追い風・課金意欲の3条件が揃っており、今回最も推奨度が高い。一方、EigoCheckの横展開である英語日記アプリは既存スキルの転用効率が最高だが、無料AI添削競合の増加で差別化が必要な状況。

**総合スコア: 83/100**

| 評価軸 | スコア | コメント |
|--------|--------|----------|
| 実装難易度 | 17/20 | SwiftUI + REST API（PDF生成・CSV出力）のみ。傭車記録・点呼記録の2機能に絞ればMVPは2ヶ月以内で完成可能。Core Dataでオフライン対応も容易 |
| 市場規模 | 16/20 | 中小運送会社（10〜50台）は全国に数万社規模。2024年問題・2025年軽貨物義務化が追い風で「今すぐ導入したい」顕在需要が高まっている |
| 競合の少なさ | 19/20 | 傭車管理専用の単体iOSアプリはほぼ存在しない。大手システムの付帯機能としてのみ内包。App Storeで実質競合なし |
| EigoCheckとの相乗効果 | 11/20 | 直接の相乗効果は低い。ただしSwiftUI/iOS開発スキル・API連携ノウハウは転用可。ユーザー層は完全に別 |
| マネタイズ可能性 | 20/20 | 月額5,000〜10,000円（法人向け）×30社=月15〜30万円。BtoBは継続率が高く、一度導入した運送会社は解約しにくい。紹介経由での拡大も見込める |

**なぜ今のオーナーに向いているか:**
デジタコ×運行管理システムのメーカー勤務というインサイダー優位が決定的。「現場が何に困っているか」「既存システムのどこが使われていないか」を競合より正確に知っている。開発前に知り合いの運送会社へヒアリングできれば、PMFの精度が格段に上がる。

**MVP設計案:**
- **最小機能**:
  1. 傭車手配記録（日付・傭車会社名・便名・金額・メモ）
  2. 月末精算一覧のPDF出力
  3. 点呼記録（ドライバー名・日時・アルコール検査結果・体調・管理者サイン）
  4. 点呼記録の1年保管・CSV書き出し
- **技術スタック**: SwiftUI + Core Data（ローカル） + CloudKit（バックアップ） + PDF Kit
- **想定工数**: 設計1週間 + 実装5〜6週間 + テスト1週間 = 約2ヶ月
- **最初の収益化方法**: 月額5,000円（法人向け）。初月無料トライアル。最初は知り合いの運送会社2〜3社でβテスト → 紹介で拡大

**リスク・注意点:**
- 点呼記録は運輸局の監査対象。法的要件（記録項目・保管期間）を正確に実装しないとクレームのリスクあり
- 導入はドライバー全員のスマホ利用が前提。高齢ドライバーへのアプリ操作教育コストが経営者の懸念になりうる
- 大手競合（MOVO Driver等）が無料で日報機能を提供している。傭車管理特化で差別化を維持すること

**MVP設計案:**
- **最小機能**: 顧客一覧 / カルテ入力（部位・施術内容・メモ・写真1〜3枚）/ 次回予定 / 過去カルテ検索
- **技術スタック**: SwiftUI + Core Data + CloudKit + PHPhotosUI
- **想定工数**: 設計1週間 + 実装4週間 + テスト1週間 = 約6週間
- **最初の収益化方法**: 無料（3顧客まで）→ 月額2,980円（無制限）のフリーミアム

**リスク・注意点:**
- Squareの無料カルテ機能・AirリザーブのCRMとの競合に注意。「シンプルさ×写真管理の充実」で差別化が必要
- 整体師向けの専門用語（経穴・経絡など）をUIに反映するかで設計難易度が変わる
- BtoC要素があり（個人事業主が利用）、App Storeのリジェクトリスクは低い

**MVP設計案:**
- **最小機能**: 日記入力画面 / AI添削リクエスト（Claude API）/ 添削結果の表示（修正箇所のハイライト+コメント）/ 日記一覧（カレンダー形式）
- **技術スタック**: SwiftUI + Claude API + iCloud（日記データ同期）
- **想定工数**: 設計1週間 + 実装3週間 + テスト1週間 = 約5週間
- **最初の収益化方法**: EigoCheckユーザー向け限定先行リリース → 月額480円（EigoCheck連携割引）

**リスク・注意点:**
- AI添削の無料化競争が進行中。「有料で使ってもらえるか」の検証が必須
- APIコスト（1添削あたり0.5〜2円程度）は月額収益とのバランスを要確認
- 英語学習アプリの有料転換率は一般的に低い（1〜5%程度）
